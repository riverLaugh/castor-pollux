# 边界条件设计与验收清单（Edge-Case Checklist）

Gemini 在 **阶段 1（写任务书）** 与 **阶段 3（L3 边界条件核验）** 按任务类型勾选对应条目，编成 `EC-1`, `EC-2`, ... 写入任务书。

---

## 1. 输入与数据边界（Input & Data）
- [ ] **空与缺失**：`null` / `None` / `undefined`、空字符串 `""`、纯空白 `"   "`、空数组 `[]`、空对象 `{}`。
- [ ] **数值极值**：`0`、`-0`、负数、最大值/溢出（32/64-bit、JS `MAX_SAFE_INTEGER`）、`NaN`、`Infinity`、浮点精度舍入误差。
- [ ] **集合与序列**：单元素集合、重复元素、已排序/逆序/乱序输入、超大长度输入（性能退化或内存暴涨）。
- [ ] **文本与编码**：非 ASCII（中文、Emoji、组合字符）、换行符差异（`\n` vs `\r\n`）、特殊转义字符（引号、反斜杠、正则元字符、glob 通配符）、超长字符串。
- [ ] **分页与切片**：`page=0` 或负数、`limit=0`、超出总页数、总数为 0、总数恰好整除 `page_size`、翻页期间底层数据增删导致的重复/漏项。

## 2. 状态、并发与幂等（State & Concurrency）
- [ ] **状态机转换**：非法状态跳转、重复触发同一转换、从空/冷启动态到运行态的首次初始化。
- [ ] **幂等与重放**：同一请求/事件重复到达两次是否会产生重复记录、重复扣费或重复副作用。
- [ ] **并发竞争**：两个请求同时读写同一资源（TOCTOU）、缓存击穿、文件/数据库锁顺序导致的死锁。
- [ ] **部分失败与原子性**：多步操作在第 N 步失败时，前 N-1 步是否回滚、重试是否安全、是否留下半成品脏文件/半成品状态。

## 3. I/O、时间与外部依赖（I/O, Time & Environment）
- [ ] **文件系统**：文件不存在（`ENOENT`）、无权限（`EACCES`）、目标是目录而非文件、符号链接、相对路径 vs 绝对路径、路径含空格或中文、并发写入是否采用原子写（临时文件 + rename）。
- [ ] **网络与上游**：超时、连接重置、429 限流、5xx 瞬时故障、上游返回空 body 或非预期 JSON schema、重试是否带退避与上限（防止无限死循环）。
- [ ] **时间与时区**：UTC vs 本地时区、跨零点/跨月/闰年（2 月 29 日）、夏令时切换（DST）、单调时钟（`monotonic`）vs 墙钟时间（`wall clock`）。
- [ ] **环境差异**：缺失环境变量、未初始化配置、只读目录、CI 无 TTY 交互环境。

## 4. 安全、权限与隐私（Security & Privacy）
- [ ] **注入与穿越**：路径穿越（`../`）、命令注入（拼接 shell 字符串而非参数数组）、SQL/模板/正则 ReDoS 注入。
- [ ] **凭证与敏感信息**：报错信息、日志、测试夹具中是否泄露 token、密码、密钥或用户敏感字段。
- [ ] **权限边界**：未授权访问、越权读写其他用户/租户资源。

## 5. 向后兼容与回归（Compatibility & Regression）
- [ ] **调用方兼容**：函数参数新增字段是否有安全默认值、返回值字段名/类型是否破坏既有调用方。
- [ ] **存量数据兼容**：旧版配置文件、旧数据库记录、旧序列化格式能否平滑读取。
- [ ] **资源清理**：文件句柄、网络连接、子进程、临时目录、定时器是否在异常路径（`finally` / `defer` / context manager）中正确释放。

## 6. 反“测试作弊”专项审计（Test Integrity — L1/L3 必查）
- [ ] **真断言而非走过场**：测试是否断言了具体输出值/状态变更，而非只断言 `is not None` 或“不抛异常”。
- [ ] **没有 mock 掉被测核心**：是否过度 mock 导致核心分支根本没执行。
- [ ] **既有测试未被削弱**：diff 中对旧测试文件的修改是否只是合理适配新契约，而非放宽断言、删除 case 或加 `skip`。
- [ ] **测试确定性与隔离**：测试是否依赖真实当前时间、随机数、外部网络或全局可变状态，是否污染仓库或残留临时文件。
